# Hub Admin

Рабочая панель администрирования и модерации Hub. Интерфейс использует реальный API `Back-Hub`, текущую cookie-сессию и серверную модель ролей `MODERATOR`, `ADMIN`, `FULL_ADMIN`.

## Возможности

- dashboard с актуальными показателями;
- поиск, фильтрация и сортировка пользователей;
- временные и постоянные блокировки, снятие блокировок и удаление аккаунта;
- просмотр и завершение пользовательских сессий;
- очередь жалоб, назначение исполнителя и история обработки;
- управление сотрудниками и ролями;
- неизменяемый журнал административных действий;
- состояние API и базы данных.

Панель не получает текст сообщений или содержимое диалогов. Для модерации доступны только идентификаторы и технические метаданные сообщения.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
yarn install --frozen-lockfile
cp .env.example .env.local
yarn dev
```

По умолчанию API доступен по адресу `http://localhost:11001/api`. Адрес можно изменить через `VITE_API_URL`.

## Проверка

```sh
yarn lint
yarn typecheck
yarn build
```

Права в интерфейсе служат для UX. Все административные операции дополнительно проверяются backend guard-ами в `Back-Hub`.
